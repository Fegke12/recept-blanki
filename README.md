# Рецептурные бланки

Учебная презентация для студентов медицинских и фармацевтических специальностей: виды рецептурных бланков, их назначение, структура и правила оформления.

- **Смотреть онлайн:** https://fegke12.github.io/recept-blanki/
- **PDF для печати:** [recept-blanki.pdf](recept-blanki.pdf)
- **PowerPoint:** [recept-blanki.pptx](recept-blanki.pptx)

18 слайдов, формат 16:9. Нормативные сведения сверены с приказом Минздрава России от 24.11.2021 № 1094н и приказом от 07.03.2025 № 100н (актуально на 1 октября 2026 года). Все данные в примерах рецептов вымышлены.
